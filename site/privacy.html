Lux PDF Viewer

Privacy Policy

Last updated: 12 October 2026

Lux PDF Viewer (“Luxy”) is a browser-based PDF viewer published by LuxRaj Kayal. This policy explains how the website handles information when you use it, including its optional Dropbox connection.

Information used by the Dropbox integration

If you choose to connect Dropbox, Luxy requests permission to read file metadata, download file contents, and upload file contents. It uses these permissions to list PDF files, download a PDF you select, and—when an edited PDF export is available and you explicitly press Sync—upload that exported PDF to the selected file’s original Dropbox path.

Luxy may process the selected file’s name and Dropbox path, plus the PDF contents you choose to open. Dropbox provides authentication and the storage APIs; your Dropbox account and files remain subject to Dropbox’s own terms and privacy policy.

Where information is processed and stored

  • Luxy is a static website hosted through GitHub Pages. The current application does not send PDF contents to a Luxy-operated application server or store them in a Luxy-operated database.
  • The Dropbox access token is held in this browser tab’s sessionStorage for the active session, rather than localStorage. Browser session restoration can vary; do not use the app on a device you do not trust.
  • Selected PDFs are downloaded to the browser for viewing. The selected Dropbox path is kept in memory for the active page session.
  • If you use Sync with an editor-exported PDF, the exported PDF is sent to Dropbox using overwrite mode and may replace the original file. Keep a backup when the original must be preserved.

Third-party services

Luxy uses Dropbox for OAuth authorization and file API requests, cdnjs to load the Dropbox JavaScript SDK, and GitHub Pages to host the website. Those services may process standard connection or operational data under their own policies. Luxy does not currently include its own analytics service or user-account system.

Your choices and security

Connecting Dropbox is optional. You can decline authorization. To revoke ongoing access, review and disconnect Luxy from your Dropbox account’s connected-app settings. Closing the browser tab usually ends the tab’s session storage, but revoking access in Dropbox is the clearest way to remove the app’s authorization. Never share your access token or use Sync unless you intend to replace the selected Dropbox file.

Changes to this policy

This policy may be updated if Luxy’s features or data handling change. The “Last updated” date above will be changed when a revision is published.

Questions or privacy concerns: open an issue in the Luxy repository. Please do not post access tokens, private documents, or other sensitive information in public issues.
