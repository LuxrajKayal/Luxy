Lux Omni

Privacy Policy

Last updated: 13 October 2026

Lux Omni (“Luxy”) is a browser-based project maintained by Luxraj Kayal (Subrata Kayal). It includes a browser-based workspace and supporting tools. Cloud-storage integrations are not currently enabled. This policy explains how the website handles information when you use it.

Where information is processed and stored

  • Luxy is a static website hosted through GitHub Pages. The current application does not send PDF contents to a Luxy-operated application server or store them in a Luxy-operated database.
  • Lux Omni Clipboard history is stored locally in this browser using IndexedDB. You can clear this history from the clipboard page or clear this website's browser data.

Lux Omni Clipboard history

Lux Omni Clipboard can keep up to ten recent items in this browser's local IndexedDB storage. Entries are ordered with the newest first and may contain text you copy using the Text Clipboard's Copy text button, images you copy using the Screenshot Clipboard's Copy screenshot button, or selected text you explicitly save using “Save to Temporary Log” from the Lux Omni page’s right-click menu. Older entries are automatically removed when the history exceeds ten items.

This history feature does not continuously monitor or record everything you copy elsewhere on your device. Selected text is saved only after you select it, right-click within Lux Omni, and explicitly choose “Save to Temporary Log”; clipboard items are recorded when you explicitly use a Copy button within Lux Omni Clipboard. The selected text is stored in this browser profile and is not sent to a Lux Omni-operated server by this feature. Importing a history item does not create a new history entry until you copy it again. Use Clear history to remove the stored entries, or clear this website’s browser data to remove locally stored records.

Third-party services

Luxy is hosted on GitHub Pages. If you use the YouTube workspace tool, content is provided by YouTube and is subject to its applicable terms and privacy policy.

Your choices and security

Use the website only in browsers and on devices you trust. Clear this website's browser data to remove locally stored records. Avoid placing private documents or other sensitive information in content you do not intend to store in this browser.
