Lux Omni

Privacy Policy

Last updated: 12 October 2026

Lux Omni (“Luxy”) is a browser-based project maintained by Luxraj Kayal (Subrata Kayal). It includes a workspace for supported files and an optional Dropbox connection. In the current build, PDF editing and export are not connected; a source PDF should not be overwritten unless an edited PDF export is supplied and you explicitly choose Sync. This policy explains how the website handles information when you use it.

Information used by the Dropbox integration

If you choose to connect Dropbox, Luxy requests permission to read file metadata, download file contents, and upload file contents. It uses these permissions to list supported files and download a file you select. For PDFs, an upload back to the selected file’s original Dropbox path is only intended when an edited PDF export is available and you explicitly press Sync. PDF editing and export are not connected in the current build, so Sync cannot replace the source with edited PDF content until an exported PDF is supplied.

Luxy may process the selected file’s name and Dropbox path, plus the PDF contents you choose to open. Dropbox provides authentication and the storage APIs; your Dropbox account and files remain subject to Dropbox’s own terms and privacy policy.

Where information is processed and stored

  • Luxy is a static website hosted through GitHub Pages. The current application does not send PDF contents to a Luxy-operated application server or store them in a Luxy-operated database.
  • The Dropbox access token is held in this browser tab’s sessionStorage for the active session, rather than localStorage. Browser session restoration can vary; do not use the app on a device you do not trust.
  • Selected PDFs are downloaded to the browser for viewing. The selected Dropbox path is kept in memory for the active page session.
  • If a future or connected editor supplies an exported PDF and you use Sync, that exported PDF is sent to Dropbox using overwrite mode and may replace the original file. The current build does not connect PDF editing/export. Keep a backup whenever the original must be preserved.

Lux Omni Clipboard history

Lux Omni Clipboard can keep up to ten recent copy actions in this browser's local IndexedDB storage. Entries are ordered with the newest first and may contain text you copy using the Text Clipboard's Copy text button or images you copy using the Screenshot Clipboard's Copy screenshot button. Older entries are automatically removed when the history exceeds ten items.

This history feature does not continuously monitor or record everything you copy elsewhere on your device. It records the relevant item when you explicitly use a Copy button within Lux Omni Clipboard. Importing a history item does not create a new history entry until you copy it again. Use Clear history to remove the stored entries, or clear this website's browser data to remove locally stored records. The history is stored in the browser profile and is not sent to a Lux Omni-operated server by this feature.

Third-party services

Luxy uses Dropbox for OAuth authorization and file API requests, cdnjs to load the Dropbox JavaScript SDK, and GitHub Pages to host the website. Those services may process standard connection or operational data under their own policies. Luxy does not currently include its own analytics service or user-account system.

Your choices and security

Connecting Dropbox is optional. You can decline authorization. To revoke ongoing access, review and disconnect Luxy from your Dropbox account’s connected-app settings. Closing the browser tab usually ends the tab’s session storage, but revoking access in Dropbox is the clearest way to remove the app’s authorization. Never share your access token or use Sync unless you intend to replace the selected Dropbox file.
