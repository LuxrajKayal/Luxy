Lux Learning Tool

Privacy Policy

Last updated: 12 October 2026

Lux All-in-One Learning Tool (“Lux Learning Tool”) is an interface-first browser workspace published by LuxRaj Kayal. The current build includes Dropbox file browsing and browser previews. YouTube embedding, closed-caption extraction, video screenshots, PDF annotation, rich Markdown formatting, screenshot/text insertion, and Markdown-note syncing are planned features and are not implemented yet. This policy explains current data handling, including the optional Dropbox connection.

Information used by the Dropbox integration

If you choose to connect Dropbox, Lux Learning Tool requests permission to read file metadata, download file contents, and upload file contents. The current file picker can list supported PDF, Markdown, and image files. The existing Sync workflow is limited to overwriting an opened PDF when a separate edited PDF Blob is available and you explicitly press Sync. Markdown-note syncing is not implemented.

Lux Learning Tool may process the selected file’s name and Dropbox path, plus the file contents you choose to open or load into the notes text area. Dropbox provides authentication and storage APIs; your account and files remain subject to Dropbox’s own terms and privacy policy.

Where information is processed and stored

  • Luxy is a static website hosted through GitHub Pages. The current application does not send PDF contents to a Luxy-operated application server or store them in a Luxy-operated database.
  • The Dropbox access token is held in this browser tab’s sessionStorage for the active session, rather than localStorage. Browser session restoration can vary; do not use the app on a device you do not trust.
  • Selected supported files are downloaded to the browser for viewing or text entry. The selected Dropbox path is kept in memory for the active page session.
  • If you use Sync with a separately supplied editor-exported PDF, the exported PDF is sent to Dropbox using overwrite mode and may replace the original file. The current Markdown notes text area does not sync notes to Dropbox. Keep a backup when the original must be preserved.

Third-party services

Lux Learning Tool uses Dropbox for OAuth authorization and file API requests, cdnjs to load the Dropbox JavaScript SDK, and GitHub Pages to host the website. The current build does not include a YouTube API integration or its own analytics service or user-account system. These services may process standard connection or operational data under their own policies.

Your choices and security

Connecting Dropbox is optional. You can decline authorization. To revoke ongoing access, review and disconnect Luxy from your Dropbox account’s connected-app settings. Closing the browser tab usually ends the tab’s session storage, but revoking access in Dropbox is the clearest way to remove the app’s authorization. Never share your access token or use Sync unless you intend to replace the selected Dropbox PDF.

Changes to this policy

This policy may be updated if Luxy’s features or data handling change. The “Last updated” date above will be changed when a revision is published.

Questions or privacy concerns: open an issue in the Luxy repository. Please do not post access tokens, private documents, or other sensitive information in public issues.
